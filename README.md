## Quick start (local)

Requirements: JDK 21 and Maven 3.9+.

```bash
mvn test                 # run the automated tests
./start.sh               # macOS/Linux: builds target/metropolitan.jar if missing, then runs it
start.bat                # Windows
```
Open http://localhost:8080. Data is kept in `./data` (persistent H2 in PostgreSQL mode). Without `JWT_SECRET` a random key is generated per start (sessions end on restart).

Optional admin account: set `ADMIN_EMAIL` and `ADMIN_PASSWORD` (8-72 chars) before starting. This is the **only** way to create an admin; public registration always creates a `MEMBER`.

## Docker with PostgreSQL

```bash
cp .env.example .env     # edit passwords and JWT_SECRET
docker compose up --build
```

## Deploy to Render (Blueprint)

Render deploys from a Git repository, not from a ZIP.

1. Extract the ZIP. Check that `render.yaml` and `Dockerfile` are at the **top level** of the folder.
2. Create a new GitHub repository and upload the extracted **contents** (not the ZIP, not an extra wrapper folder). Commit `.gitignore` too.
   ```bash
   cd metropolitan && git init && git add . && git commit -m "Metropolitan" && git branch -M main
   git remote add origin https://github.com/<you>/metropolitan.git && git push -u origin main
   ```
3. In Render: **New > Blueprint**, connect GitHub, choose the repository, and apply. Render creates the PostgreSQL database and the web service.
4. When prompted for `ADMIN_EMAIL` / `ADMIN_PASSWORD`, enter them for an admin account or leave blank.
5. Wait for the Docker build (several minutes), open the `onrender.com` URL, and register. `JWT_SECRET` was generated by Render; database host, name, user and password are wired in automatically; the app reads Render's `PORT`.

Health check: `/actuator/health`.

### Free-tier limitations (as documented by Render at the time of writing; re-check https://render.com/docs/free)
- **Free web services spin down after 15 minutes without traffic**; the next request takes about a minute to wake the service. Open WebSocket connections drop when it sleeps; the page reconnects automatically.
- **Free PostgreSQL expires 30 days after creation**, with a 14-day grace period to upgrade before it is deleted. **Your data is not permanent on the free plan.** Back up (`pg_dump`) or upgrade the database for anything you need to keep.
- Free instances are small (limited RAM/CPU), have 1 GB database storage, and one free database per workspace. This is for demos and assignments, not production.

## Features mapped to the assignment

| Requirement | Where |
|---|---|
| REST API, registration/login, BCrypt, JWT | `AuthController`, `AuthService`, `JwtService`, `SecurityConfig` |
| Task CRUD, priority, due date, assignee | `TaskController`, `TaskService`, `Task` |
| JPA + Flyway + PostgreSQL/H2 | `db/migration/V1__initial_schema.sql`, `database/schema.sql`, profiles |
| WebSocket create/edit/reassign/delete | `RealtimeHub` (`/ws`), events published after commit |
| Privacy in REST and WebSocket | `TaskService.visible/list`, `RealtimeHub.onTaskChange` audience filter |
| Roles; no public admin | `RegisterRequest` has no role field; service forces `MEMBER`; `AdminBootstrap` |
| Validation, errors, optimistic locking | Bean Validation, `ApiExceptionHandler`, `@Version` + `version` check (409) |
| Tests | `src/test/java/com/metropolitan` (`AuthTests`, `TaskTests`, `WebSocketPrivacyTests`) |

## API examples

Replace `$TOKEN`. See `docs/API.md` for every endpoint.

```bash
curl -s -X POST localhost:8080/api/auth/register -H 'Content-Type: application/json' \
  -d '{"name":"Sujal Jha","email":"sujal@example.com","password":"Passw0rd!x"}'
curl -s -X POST localhost:8080/api/tasks -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"title":"Draft report","description":"v1","status":"TODO","priority":"HIGH","dueDate":"2030-01-15","assigneeId":null}'
curl -s -X PUT localhost:8080/api/tasks/1 -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"title":"Draft report","description":"v2","status":"IN_PROGRESS","priority":"HIGH","dueDate":"2030-01-15","assigneeId":null,"version":0}'
```
